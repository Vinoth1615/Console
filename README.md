# 🚗 Car Rental System – Java Project

A **console-based Car Rental Management System** built in **Java**.
This project allows admins to manage cars and customers, while customers can rent and return cars seamlessly.
It demonstrates **Object-Oriented Programming (OOP)** concepts like encapsulation, abstraction, and real-world problem-solving.

---

## ✨ Features

### 👨‍💼 Admin

* ➕ Add new cars
* ❌ Remove cars by license plate number
* 📋 View all cars
* 💰 Track total revenue

### 👤 Customer

* ➕ Register as a customer
* 📋 View available cars
* 🚘 Rent cars by ID & license number
* 🔄 Return rented cars and view cost

---

## 📂 Project Structure

```
CarRentalSystem.java
 ├── Car class       → Car details (ID, name, brand, plate, price, availability)
 ├── Customer class  → Customer details (ID, name, license, rented car info)
 └── Main class      → Handles menu, options, and system workflow
```

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/yourusername/car-rental-system.git
   ```
2. Navigate to the project folder:

   ```bash
   cd car-rental-system
   ```
3. Compile the program:

   ```bash
   javac CarRentalSystem.java
   ```
4. Run the program:

   ```bash
   java CarRentalSystem
   ```
